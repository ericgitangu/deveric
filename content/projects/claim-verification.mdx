# Overview

An application for turning submitted claims into traceable assessments. A staged pipeline extracts checkable statements, gathers supporting sources, validates citations, and routes uncertain or high-risk cases for review rather than forcing a verdict.

## Capabilities

- Accept claims from automated feeds or direct submissions.
- Track each assessment through an event-driven workflow with retry-safe processing.
- Publish evidence and calibrated confidence alongside each result.
- Stream status updates to the user interface.

## Stack

TypeScript and Python services, a web application, PostgreSQL, queued event delivery, and language-model-assisted analysis.
