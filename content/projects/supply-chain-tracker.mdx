# Context and problem

Supply-chain records are difficult to verify when inventory state, user permissions, and provenance events are held in disconnected workflows. This project explores how a web application can make item history visible while allowing selected events to be independently checked.

## Engineering approach

- **Role-aware workflows.** Wallet-based authentication gates inventory and tracking actions according to a user's role.
- **Shared operational state.** Inventory updates and movement status are managed through application APIs and persisted in a document database.
- **Verifiable events.** Selected supply-chain records can be checked against blockchain transactions rather than relying only on a mutable application view.
- **Live status.** The interface surfaces updates as products move through the tracked workflow.

## Outcomes and trade-offs

The prototype combines inventory management, access control, and transaction verification in one web experience. It demonstrates the integration boundary between a conventional application data store and a public ledger; the README does not claim a production deployment or quantify operational impact.

## Stack

- Next.js 14, React 18, and Tailwind CSS
- Next.js API routes and MongoDB Atlas
- Wallet Connect and Ethereum/Web3 integration
