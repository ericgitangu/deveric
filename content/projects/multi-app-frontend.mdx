# Overview

A monorepo structure for coordinating multiple web applications and the packages they share. Common tooling and dependencies make cross-application changes easier to maintain.

## Capabilities

- Organize several frontend surfaces in one workspace.
- Share UI and application packages where appropriate.
- Use consistent build and development conventions.
