# Overview

A small data ingestion system that moves structured records into a relational database while making failures visible and repeatable.

## Capabilities

- Validate incoming rows before writing.
- Keep repeated imports safe through idempotent processing.
- Report rejected records and roll back when data quality falls below a configured threshold.
- Support dry runs that produce a report without changing stored data.

## Stack

Python, PostgreSQL, Docker, and automated tests.
