# Overview

A retail experience paired with an administrative workspace and a shared service API. The customer-facing app is designed for mobile use, while staff tools support catalog updates and request handling.

## Capabilities

- Present products and services through an installable web experience.
- Support low-connectivity use with progressive web app features.
- Provide separate customer and administration interfaces.
- Connect application workflows to a shared API and relational data store.

## Stack

Next.js, React, Rust, PostgreSQL, and infrastructure-as-code.
