# Overview

A service layer that centralizes business rules and data access for a multi-role mobility application. Separate clients can use consistent endpoints for user, trip, and operations workflows.

## Capabilities

- Expose application workflows through a shared API.
- Coordinate trip and account state across client applications.
- Keep backend concerns separate from presentation-layer clients.
