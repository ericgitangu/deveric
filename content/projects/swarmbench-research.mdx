# Context and problem

Multi-agent systems are often presented as a general way to improve AI performance, but delegation only helps when task structure and the dominant failure mode support it. This study tests that claim against both software-work tasks and structured research tasks, asking where decomposition provides a measurable advantage and where it adds coordination cost without removing the underlying limitation.

## Method and engineering approach

- **Pre-registered hypotheses.** Three hypotheses connected task scale and decomposition to expected performance; each was evaluated using explicit falsification criteria rather than post-hoc narrative.
- **Repeatable task packages.** Seven attempts used containerized environments, written instructions, a decomposition, and an explicit verifier, making the evaluation setup inspectable and reproducible.
- **Two task shapes.** The study compared work requiring changes across a codebase with tasks that can be split into independent structured items.
- **Measured limitations.** Each condition had a single trial, so the results are bounded evidence for mechanism discovery, not a basis for broad statistical claims.

## Findings and outcomes

The trials indicate that decomposition is most useful when work consists of independent items or when it prevents context from becoming the limiting factor. It does not by itself overcome a model capability ceiling, poor retrieval precision, or disagreement about which source is authoritative. The key contribution is a practical bottleneck framework for deciding when to use agent coordination, alongside documented evidence that the advantage is task-dependent rather than automatic.

## Technical approach

- Containerized Python task environments with explicit verifiers
- Multi-agent and single-agent execution paths
- Structured extraction and executable software-task checks
- Reproducible research artifacts and a paper documenting limitations
