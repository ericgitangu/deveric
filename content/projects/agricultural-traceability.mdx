# Overview

A traceability system that connects field activity with downstream supply-chain records. Geospatial data, role-specific dashboards, and verifiable transaction records help participants follow a product from source to buyer.

## Capabilities

- Record field observations and supply-chain handoffs.
- Review geospatial and compliance information through role-specific dashboards.
- Preserve traceability events in an auditable ledger.
- Coordinate operational updates across web and API services.

## Stack

React, Django, PostgreSQL with geospatial extensions, and smart-contract integrations.
