# Overview

A compact support workflow for creating, reviewing, updating, and closing tickets. The web interface communicates with a typed API backed by a relational database.

## Capabilities

- Create and edit tickets with validated fields.
- Filter and sort records through indexed database queries.
- Generate a type-safe client from the API schema.
- Run the web application and API together in a containerized development environment.

## Stack

FastAPI, Python, PostgreSQL, SQLAlchemy, Next.js, and TypeScript.
